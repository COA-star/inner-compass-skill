# 内在困境支持 Skill

一个面向日常心理困扰的 Codex Skill，通过温暖、非诊断式的苏格拉底问答，帮助使用者逐步看清自己的处境、情绪、想法、需要与下一步行动。

它适合用于自我否定、焦虑、羞耻、低落、孤独、关系冲突、讨好、纠结、行动困难和强烈自我批评等情境。

> 本项目提供心理教育、情绪梳理与求助导航，不是心理诊断、心理治疗、医疗建议或紧急救援服务。

## 设计目标

- 温暖但不空泛，不用“你已经很棒了”代替真实理解。
- 专业但不越界，不根据一次聊天诊断心理疾病或人格类型。
- 每轮只推进一个主要问题，避免把交流变成审问。
- 同时维护四条内部线索：正在担忧什么、可能为何如此、接下来怎么做、是否存在安全风险。
- 尊重使用者的自主性，允许不同意、跳过、暂停或更换方向。
- 发现自伤、轻生、虐待、暴力或严重精神状态异常时，暂停深度探索，优先连接现实中的安全支持。

## 核心对话过程

1. **建立联系**：准确回应对方正在承受的重量。
2. **必要时检查安全**：危险信号优先于普通心理探索。
3. **把问题具体化**：从“我很差”回到最近发生的一件事。
4. **辨认体验**：看见情绪、身体感觉和行动冲动。
5. **听见内心语言**：找到反复出现的判断、预测或规则。
6. **理解形成条件**：探索它可能在保护什么，同时考虑家庭、关系、环境和现实压力。
7. **寻找需要和价值**：例如安全、尊重、归属、自主、能力感或公平。
8. **增加心理弹性**：区分事实与解释，形成可信而非虚假的新视角。
9. **选择微小行动**：找到一天内可尝试、可撤回的下一步。
10. **形成阶段性总结**：说明已经理解了什么，还有什么不确定。

## 知识来源与取舍

Skill 由项目本地心理学文库归纳而来，主要吸收：

- WHO/UNICEF 心理健康与系统支持资料；
- WHO 压力管理指南中的着陆、解套、价值行动、接纳和友善；
- OpenStax《心理学》中的研究、发展、情绪、社会心理、压力与治疗基础；
- 非暴力沟通中的观察、感受、需要和请求；
- 认知行为、接纳与承诺、动机式访谈和可信自我同情的通用原则；
- 阿德勒相关书籍中关于归属、边界和微小行动的可取部分。

项目不会把弗洛伊德、荣格、阿德勒等历史理论当成诊断依据，也明确拒绝“创伤不存在”“过去不重要”“焦虑是自己选择的”等可能造成二次伤害的说法。
